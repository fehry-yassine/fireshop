# Roles and Features

## Roles

### Buyer

- Register and log in.
- Browse structured categories.
- Search and filter products.
- View product details and vendor information.
- Add products to cart.
- Place single-vendor Cash on Delivery orders.
- Track internal order status.

### Vendor

- Register as a vendor.
- Wait for admin approval.
- Create and update products.
- Manage product stock.
- View orders for their store.
- Update internal order status.

### Admin

- Manage users.
- Approve or reject vendors.
- Approve, reject, or hide products.
- View all orders.
- Manage categories.
- Manage manual featured/offers sections.
- Monitor basic dashboard statistics.

## MVP Features

- Authentication with buyer, vendor, and admin roles.
- Vendor profile approval.
- Product catalog with maximum 2 category levels.
- Product search and filtering.
- Cart and single-vendor COD checkout.
- Order creation and internal status tracking.
- Vendor order management.
- Admin dashboard for approvals and supervision.
- Basic dashboard statistics.
- Manual featured/offers sections.

## V1 Product Decisions

- Tunisia-focused local product marketplace.
- Multiple local product categories, not only handmade products.
- Single-vendor checkout per order.
- Maximum 2 category levels.
- COD only.
- Internal order status tracking only.
- Basic dashboard statistics.
- Manual featured/offers sections.
- French presentation language with English technical terms where needed.

## First Release Rule

The first release must prove the complete marketplace cycle:

Buyer finds product -> buyer places a single-vendor COD order -> vendor prepares order -> admin supervises -> buyer tracks/receives product.
